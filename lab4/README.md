## Задача 1. Тематическое моделирование

Пример запуска с фиксированным количеством тем:
python .\lab4\topic_modeling.py --dataset news --method both --topics 10 --compare --output news

Автоматический подбор числа тем:
python .\lab4\topic_modeling.py --dataset news --method both --topics auto --compare --output news_auto
python .\lab4\topic_modeling.py --dataset products --method both --topics auto --compare --output products_auto

Аргументы:
--datase - tnews, products, mixed
--method - lda, nmf, both
--topics - Число тем или auto
--compare - Сохранить сравнение coherence
--output - Префикс выходных файлов
--top-words - Количество слов в теме, по умолчанию 10

LDA работает на мешке слов Gensim. NMF обучается на матрице TF-IDF
При --topics auto перебираются значения K от 3 до 20, для каждого вычисляется coherence c_v

### Результаты тематического моделирования

Новости LDA 10 тем, согласованность 0.6754
Новости NMF 9 тем согласованность 0.8899
Товары LDA 3 темы согласованность 0.6387
Товары NMF 5 тем согласованность 0.7540

На обоих наборах NMF показала более высокий результат

В новостях выделились темы научных мероприятий, цифрового образования, разработок, поздравлений, студенческого спорта, инженерной школы и медиацентра
В товарах NMF выделила группы Acer, Dell, Lenovo, Asus и отдельную тему с отзывами покупателей

Для каждой модели сохраняются:

## Задача 2. Кластеризация городов

Сбор данных:
python .\lab4\collect_city_dishes.py
python .\lab4\collect_wikivoyage_dishes.py
python .\lab4\collect_regional_dishes.py

Для каждого города строится вектор. Каждое измерение соответствует блюду, а значение показывает долю страниц города, где это блюдо упоминается:
частота = страницы с блюдом/все страницы города

Синонимы объединяются.Общие блюда, которые не помогают различать регионы, исключаются

Запуск кластеризации:
python .\lab4\city_clustering.py --clusters 4 --output cities

Применяются три метода:

- k-means;
- иерархическая кластеризация Ward;
- спектральная кластеризация с косинусной близостью

### Результаты кластеризации

K-means и иерархический метод дали одинаковое разбиение:

- Пермь, Кунгур и Петрозаводск;
- Москва, Санкт-Петербург и Хабаровск;
- Казань и Уфа;
- Новосибирск.

Проверка содержательных пар:

- Пермь и Кунгур находятся вместе во всех трёх методах;
- Казань и Уфа находятся вместе во всех трёх методах

Метрики:
- Silhouette k-means- 0.3188;
- Silhouette иерархического метода - 0.3188;
- Silhouette спектрального метода - 0.3034;
- Rand k-means/иерархический - 1.0000; 
- Rand k-means/спектральный-  0.7188;
- Rand иерархический/спектральный-  0.7188 

Спектральный метод предупреждает о неполной связности графа и немного отличается от двух других, поэтому наиболее устойчивым считаем общее разбиение k-means и иерархического метода
