# Практика 6. Анализ и семантическая обработка видеоданных

Чернецов А.А. АСУ4-25-1м

Обрабатываюся ролики с видеохостингов и локальные файлы. Для каждого видео извлекаются кадры, аудио и метаданные. YOLO распознаёт объекты, Whisper создаёт транскрипт, объединяются результаты в события с временными метками. В интерфейсе можно выбрать ролик, посмотреть его тематический кластер и статистику объектов, найти слово или объект и перейти к соответствующему моменту видео

## Установка
Использовался Python 3.10, FFmpeg и ffprobe должны быть прописаны в PATH.
Создание окружения и установка библиотек:
py -3.10 -m venv .\lab5\.venv
.\lab5\.venv\Scripts\Activate.ps1
python -m pip install -r .\lab5\requirements.txt

## Источники видео
В videos.txt указывается в каждой строке ссылка на видео или путь

## Запуск

Команды выполняются из корня репозитория
- python .\lab5\collect.py
- python .\lab5\decompose.py
- python .\lab5\vision.py --confidence 0.35
- python .\lab5\speech.py --model base --language ru
- python .\lab5\events.py
- python .\lab5\topics.py --clusters 2
- python .\lab5\app.py
После последней команды открывается страница: http://127.0.0.1:7860

Промежуточные результаты сохраняются, поэтому повторный запуск пропускает уже выполненные этапы, предусмотрен ключ --force для пересчёта

## Порядок анализ

- ollect.py получает ролики через yt-dlp, ограничивает качество 720p и сохраняет доступные метаданные. Для локальных файлов размер, разрешение и кодек читаются через ffprobe. Если источник недоступен, причина записывается в collection.json

- decompose.py извлекает монофоническую аудиодорожку 16 кГц. Частота кадров подбирается по длительности видео: от 0,1 до 1 кадра в секунду. Это не даёт длинным роликам создавать слишком много лишних изображений

- vision.py применяет yolov8n.pt с порогом уверенности 0,35. Для каждого срабатывания сохраняются класс, уверенность, координаты рамки и время кадра

- speech.py использует faster-whisper на процессоре. Сегменты речи сохраняются с началом и концом. Дополнительно вычисляется RMS громкости по секундным окнам. Порог громкого участка рассчитывается как среднее плюс одно стандартное отклонение, но не ниже 0,02

- events.py склеивает подряд идущие детекции одного класса в интервалы. Сегменты речи и громкие окна также преобразуются в события

- topics.py объединяет название, описание, транскрипт и названия объектов. Русские слова лемматизируются через pymorphy3. Затем применяются TF-IDF и KMeans

## Результаты

Обработано 6 роликов: три обзора еды и три ролика о технике

- Роликов  6 
- Проанализированных кадров  1266 
- Детекций объектов  3153 
- Сегментов речи  240 
- Временных событий  819 
- Тематических кластеров  2 
- Silhouette  0,0217 

KMeans разделил ролики в соответствии с ручным делением:

- кластер 0 - обзоры чипсов, лапши и продуктов;
- кластер 1 - навесное оборудование, выставки и сельхозтехника.

Основные слова кластера еды: рубль, соус, грамм, вкус, курица
Основные слова кластера техники: техника, выставка, трактор, завод, оборудование

Низкое значение silhouette показывает слабое разделение в пространстве TF-IDF. Корпус небольшой, а разговорные тексты содержат много общих слов. При этом состав обоих кластеров совпал с ручной проверкой
Вручную проверены несколько событий YOLO, фрагментов транскрипта и переходов по времени. Проверенные переходы приводят примерно к нужному месту
