## Запуск

Установка зависимостей:
python -m pip install -r .\lab2\requirements.txt

Сбор данных:
python .\lab2\lab2.py

Построение графа:
python .\lab2\graph.py

Для создания PDF и SVG нужен установленный Graphviz, команда `dot` должна быть доступна в терминале.

Получение изображения дня:
python .\lab2\potd.py

Сначала программа запрашивает русское описание, если его нет, используется английское
